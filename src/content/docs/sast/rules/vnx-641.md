## Overview

VNX-641 maps to [CWE-641: Improper Restriction of Names for Files and Other Resources](https://cwe.mitre.org/data/definitions/641.html). A file name is restricted by the part of it that decides how the server treats the file: the text after the **last** dot. Code that looks anywhere else lets a double extension through: `avatar.jpg.php` contains `.jpg`, and `shell.png.php` has `png` after its first dot, yet both are stored and served as PHP.

Reported, on a file-name expression (`filename`, `fileName`, `fname`, `originalname`, `f.filename`, `file.name`, `getOriginalFilename()`, `getSubmittedFileName()`, `$_FILES[...]['name']`, or a variable assigned straight from one in the 15 lines above):

- **The extension taken from the first dot:** Python `split('.')[1]`, `split('.', 1)[1]`, `partition('.')`; JavaScript and Java `split('.')[1]` / `split("\\.")[1]` and `substring`/`substr`/`slice` from `indexOf('.')`; PHP `explode('.', $name)[1]`, `substr($name, strpos($name, '.'))`, `strstr($name, '.')`.
- **An allowlist tested as a substring:** Python `'.png' in name` or `any(ext in name for ext in ALLOWED)`; JavaScript `includes('.jpg')` or `indexOf('.jpg') !== -1`; Java `contains(".pdf")` or `indexOf(".pdf") >= 0`; PHP `strpos`/`stripos`/`strstr($name, '.jpg')`; and an extension regex with no `$` anchor in JavaScript `.test()`/`.match()` or PHP `preg_match()`.

## What Gets Flagged

```python
ext = f.filename.split(".")[1].lower()          # FLAGGED: first dot
if ".png" in f.filename:                        # FLAGGED: substring
```

```javascript
if (file.originalname.includes('.jpg')) return cb(null, true);   // FLAGGED
if (/\.(pdf|docx)/i.test(file.originalname)) return cb(null, true);  // FLAGGED: no $ anchor
```

```php
$ext = explode('.', $name)[1];                  // FLAGGED
```

## What Is Not Flagged

- The final extension: `rsplit('.', 1)`, `split('.')[-1]`, `split('.').pop()`, `lastIndexOf('.')`, `os.path.splitext`, `path.extname`, `pathinfo`, `FilenameUtils.getExtension`.
- `endswith`/`endsWith` checks and `$`-anchored patterns.
- The same calls on values that are not file names (versions, host names, e-mail addresses, JWTs), comments and string literals.

Storing an upload under the client's name is [VNX-66](/sast/rules/vnx-66/); a case-sensitive extension check is [VNX-178](/sast/rules/vnx-178/).

## Remediation

Take the final extension, lower-case it, compare it with an allowlist, and store the file under a generated name:

```python
ext = os.path.splitext(f.filename)[1].lower()
if ext not in {".png", ".jpg", ".gif"}:
    abort(400)
f.save(os.path.join(UPLOADS, f"{uuid.uuid4().hex}{ext}"))
```
