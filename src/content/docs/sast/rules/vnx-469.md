## Overview

VNX-469 maps to [CWE-469: Use of Pointer Subtraction to Determine Size](https://cwe.mitre.org/data/definitions/469.html). Reports C/C++ pointer subtraction between pointers that provably point into different objects: two distinct sized arrays, two separate allocations (malloc, calloc, strdup, new[]), or iterators of two different containers. The result is undefined and cannot serve as a size. Pointers that may share an object, members, element values, linked-list nodes and comments are not reported.

## What gets flagged

```c
// FLAGGED: two separate allocations
char *first = malloc(count);
char *second = malloc(count);
size_t span = second - first;

// FLAGGED (C++): iterators of different containers
auto n = std::distance(left.begin(), right.end());

// NOT FLAGGED: both pointers point into the same buffer
const char *end = strchr(line, ' ');
return end - line;
```
