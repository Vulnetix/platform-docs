## Overview

VNX-941 maps to [CWE-941: Incorrectly Specified Destination in a Communication Channel](https://cwe.mitre.org/data/definitions/941.html). Data sent over a channel whose destination is left open is delivered to whoever is listening: the page a popup or iframe now shows, or any installed app that registers for a broadcast action.

## What Gets Flagged

```javascript
window.opener.postMessage({ type: 'oauth', token }, '*');   // flagged
frame.contentWindow.postMessage(session, '*');               // flagged
```

```java
Intent changed = new Intent("com.example.PASSWORD_CHANGED");
changed.putExtra("password", newPassword);
sendBroadcast(changed);                                      // flagged
```

Not flagged: `postMessage` with an explicit target origin; `postMessage` to the page's own window and Worker/MessagePort `postMessage`; explicit Intents (`new Intent(ctx, X.class)`, `setPackage`, `setComponent`); broadcasts with a receiver permission; `LocalBroadcastManager`; intents without extras; comments and string literals.

## Remediation

Name the recipient: pass the expected origin to `postMessage`, and send broadcasts with `setPackage(...)`, a receiver permission, or `LocalBroadcastManager`.

```javascript
window.opener.postMessage({ type: 'oauth', token }, 'https://app.example.com');
```
