## Overview

VNX-472 maps to [CWE-472: External Control of Assumed-Immutable Web Parameter](https://cwe.mitre.org/data/definitions/472.html). Reports server-owned values taken from the client: a price, total, discount or privilege field (role, isAdmin) read from the request body, query, params or cookies in JavaScript/TypeScript, and hidden form inputs in templates that carry a price, privilege or user id. Admin back-office routes, price fields that are only compared, user-chosen fields such as amount or quantity, CSRF tokens, tests and comments are not reported.

## Why this matters

This weakness class (External Control of Assumed-Immutable Web Parameter) creates a concrete exploit surface: the rule searches for the concrete source-level patterns most commonly associated with CWE-472 and surfaces them for review. Each finding should be evaluated in context, the rule catches the pattern, not the context.

## What gets flagged

```javascript
// FLAGGED: the client sets the price it pays
price: req.body.price,

// FLAGGED: the client claims its own privilege
if (req.cookies.isAdmin === 'true') { return next(); }

// NOT FLAGGED: the submitted price is only validated against the server's
if (req.body.price !== product.price) { return res.status(400).end(); }
```

```html
<!-- FLAGGED: a hidden input is not read-only -->
<input type="hidden" name="price" value="<%= item.price %>">
```
