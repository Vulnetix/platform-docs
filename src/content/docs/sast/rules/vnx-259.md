## Overview

A password written into the call that uses it ships in the source and in every build, is visible to everyone with repository access, and cannot be rotated without a release. This maps to [CWE-259: Use of Hard-coded Password](https://cwe.mitre.org/data/definitions/259.html).

This rule covers positional arguments. A literal assigned to a password-named variable, key, keyword argument or configuration entry is reported by VNX-SEC-014 (and in Java by VNX-JAVA-025).

## What Gets Flagged

- Python: `.login(user, "pw")` (smtplib, ftplib, imaplib; the user may be a variable), `HTTPBasicAuth`/`HTTPDigestAuth(user, "pw")`, `auth=("u", "pw")`, `pymysql`/`MySQLdb.connect(host, user, "pw")`, LDAP `simple_bind_s(dn, "pw")`.
- Java: `env.put(Context.SECURITY_CREDENTIALS, "pw")`, `Transport.send(msg, user, "pw")`, `transport.connect(host, user, "pw")`, `new UsernamePasswordAuthenticationToken("u", "pw")`, `DriverManager.getConnection(url, user, "pw")`, `new PasswordAuthentication(user, "pw".toCharArray())`.
- JavaScript: `new Sequelize(db, user, "pw")`, `pass: "pw"` inside an `auth: { }` object (nodemailer), express-basic-auth `users: { name: "pw" }`, `.auth("u", "pw")`, ldapjs `client.bind("cn=admin,dc=example,dc=org", "pw", cb)`.
- PHP: `mysqli_connect`/`new mysqli`/`mysql_connect(host, user, "pw")`, `new PDO(dsn, user, "pw")`, `ldap_bind`, `ftp_login`.
- Ruby: `ftp.login(user, "pw")`, `.basic_auth(user, "pw")`, `Net::SMTP.start(host, port, helo, user, "pw", :login)`.
- Go: `smtp.PlainAuth(id, user, "pw", host)`, `SetBasicAuth(user, "pw")`, `url.UserPassword(user, "pw")`, `ssh.Password("pw")`, go-ldap `l.Bind("cn=svc,dc=example,dc=com", "pw")`.
- C#: `new NetworkCredential(user, "pw")`.

```python
server.login("alerts@example.org", "Wint3r-Is-Coming")       # flagged
```

```go
auth := smtp.PlainAuth("", "alerts@example.org", "Sm7p-Passw0rd", host)   // flagged
```

Not flagged: values from the environment, configuration or a variable, empty strings, templated values (`${...}`, `{{...}}`, `%s`, `$var`), placeholders (`xxx`, `***`, `<password>`, `your-password`, or the bare words password, pass, secret, user), comments, strings that only mention the call, and test code.

## Remediation

```python
server.login(os.environ["SMTP_USER"], os.environ["SMTP_PASSWORD"])
```

Load credentials from a secret manager or the environment at runtime, and rotate any password that has been committed.
