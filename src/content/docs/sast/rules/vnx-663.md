## Overview

VNX-663 maps to [CWE-663: Use of a Non-reentrant Function in a Concurrent Context](https://cwe.mitre.org/data/definitions/663.html).

- **Java:** a `static` field of type `SimpleDateFormat`, `DateFormat`, `DecimalFormat`, `NumberFormat`, `MessageFormat`, `ChoiceFormat`, `MessageDigest`, `Mac`, `Cipher`, `Signature` or `java.util.regex.Matcher`, shared by every thread.
- **C/C++:** a call to `strtok`, `localtime`, `gmtime`, `ctime`, `asctime`, `getpwnam`, `getpwuid`, `getgrnam`, `getgrgid`, `gethostbyname`, `gethostbyaddr`, `getservbyname`, `getlogin`, `ttyname`, `strsignal`, `ecvt`, `fcvt`, `crypt` or `inet_ntoa` (also as `std::`) in a file that starts threads (`pthread_create`, `std::thread`/`std::jthread`, `std::async`, `CreateThread`, `_beginthreadex`, `#pragma omp`).

Not reported: `ThreadLocal` holders, `DateTimeFormatter` and `Pattern` (thread-safe), local and instance formatters, a static formatter the same file locks with `synchronized (NAME)` or uses only inside `synchronized` methods, the `_r` variants, member calls and lookalike names, declarations that share a libc name, files that start no threads (a thread marker in a comment does not count), comments and string literals.

## Why This Matters

Two threads formatting with one `SimpleDateFormat` corrupt its internal `Calendar` and return wrong dates or throw. `strtok` and `localtime` keep their state in a static buffer, so one thread's call silently overwrites another's result.

## What Gets Flagged

```java
private static final SimpleDateFormat ISO = new SimpleDateFormat("yyyy-MM-dd'T'HH:mm:ss");   // FLAGGED
private static MessageDigest sha256;                                                       // FLAGGED
```

```c
char *tok = strtok(line, ",");          /* FLAGGED: file calls pthread_create */
struct tm *t = localtime(&now);         /* FLAGGED */
```

## Remediation

1. Java: use `java.time.format.DateTimeFormatter`, a `ThreadLocal`, or a new instance per call (`MessageDigest.getInstance` is cheap).
2. C/C++: use `strtok_r`, `localtime_r`, `gmtime_r`, `getpwuid_r`, `getaddrinfo`/`inet_ntop`.
