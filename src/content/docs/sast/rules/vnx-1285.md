## Overview

VNX-1285 maps to [CWE-1285: Improper Validation of Specified Index, Position, or Offset in Input](https://cwe.mitre.org/data/definitions/1285.html).

## Why This Matters

A position from the request used directly as a list index lets the client pick any element. In Python a negative index silently counts from the end. An out-of-range index raises an error or yields `undefined`, and `.pop()`/`.splice()` can remove an element the client was never offered.

## What Gets Flagged

```python
idx = int(request.args.get("index", 0))
return SLIDES[idx]

job = JOBS[int(request.GET["pos"])]
```

```javascript
const i = parseInt(req.params.index, 10);
res.json(items[i]);

tracks.splice(+req.body.position, 1);
```

Not flagged: an index checked against `0` and `len()`/`.length` before use, slices (`rows[offset:offset + 20]`, `.slice()`), lookups keyed by a string (`users[req.params.id]`).

## Remediation

1. Check `0 <= index < len(items)` (or `index >= 0 && index < items.length`) before indexing, and return 400/404 otherwise.
2. Prefer looking records up by an identifier rather than by position.
