## Overview

VNX-222 maps to [CWE-222: Truncation of Security-relevant Information](https://cwe.mitre.org/data/definitions/222.html). Bounded string functions prevent overflow by cutting the result short, and they report that they did so only through a return value that is easy to ignore. When the truncated buffer then decides something, the decision is made on the wrong value: `"%s/%s.txt"` loses its extension and opens a different file, a truncated user name can equal a privileged one, a truncated command runs without its trailing options, and a truncated log line loses the part an investigator needed.

The rule reports a statement that discards the result of `snprintf`, `vsnprintf`, `_snprintf`, `sprintf_s`, `strncpy`, `strncpy_s`, `strcpy_s`, `strlcpy`, `strncat`, `strlcat` or `g_strlcpy` into an array declared in the same function, when within twelve lines the buffer is passed to:

- file calls: `open`, `openat`, `fopen`, `creat`, `access`, `stat`, `realpath`, `unlink`, `remove`, `rename`, `chmod`, `chown`, `mkdir`, `rmdir`, `chdir`, `chroot`, `truncate`, `std::ifstream`/`ofstream`/`fstream`, `.open()`;
- process and library loading: the `exec` family, `system`, `popen`, `dlopen`, `LoadLibrary`;
- network: `connect`, `bind`, `getaddrinfo`, `gethostbyname`, `SSL_set_tlsext_host_name`, `X509_check_host`;
- decisions and records: `strcmp`/`strncmp`/`strcasecmp`/`memcmp`, `crypt`, `setenv`/`putenv`, `syslog`;
- a Unix socket path copied into `addr.sun_path` and then passed to `bind` or `connect`.

A format counts only when it inserts a string (`%s`) or takes its format from a variable: `"%d"` into a 256-byte buffer cannot truncate.

## What gets flagged

```c
char path[256];
snprintf(path, sizeof(path), "%s/%s.txt", base, name);   /* FLAGGED */
return open(path, O_RDONLY);
```

```c
char user[16];
strlcpy(user, login, sizeof(user));                      /* FLAGGED */
return strcmp(user, "administrator") == 0;
```

## What is not flagged

- A checked result: `int n = snprintf(...); if (n < 0 || (size_t)n >= sizeof(path)) return -1;` or `if (strlcpy(...) >= sizeof(user))`.
- A later comparison against `sizeof` or `strlen(buf)` before the use, or the source length tested against the buffer size just before the copy: `if (strlen(sock_path) >= sizeof(addr.sun_path)) return -1;`.
- Buffers that are only displayed (`printf`, `puts`, UI calls), integer-only formats, comments, strings and test code.

## Remediation

```c
int n = snprintf(path, sizeof(path), "%s/%s.txt", base, name);
if (n < 0 || (size_t)n >= sizeof(path))
	return -ENAMETOOLONG;
```

## Suppressing this rule

Put a `nosec` comment on the line, or on line 1 to cover the whole file. Use the comment marker of the file's language (`#`, `//`, `--` or `;`):

```text

```
