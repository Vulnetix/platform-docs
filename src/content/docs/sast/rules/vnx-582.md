## Overview

VNX-582 maps to [CWE-582: Array Declared Public, Final, and Static](https://cwe.mitre.org/data/definitions/582.html). It reports a `public static final` array field in Java (any modifier order, `int[] X` or `String X[]`, initialised inline or in a static block), an array constant declared in a Java interface (implicitly `public static final`), and a `public static readonly` array in C#.

## Why this matters

`final` and `readonly` fix the reference, not the contents. Any class can write `Limits.ALLOWED_ROLES[0] = "guest"` and change what every other caller sees, which turns a constant allow-list, key table or limit into shared mutable state.

## What gets flagged

```java
public static final int[] RETRY_DELAYS = {100, 200, 400};
public final static String[] ALLOWED_ROLES = new String[] {"admin", "editor"};
public static final String ADMINS[] = {

public interface Scopes {
    String[] DEFAULT_SCOPES = {"read", "write"};
}
```

```csharp
public static readonly string[] TrustedHosts = { "api.example.com" };
```

Not flagged: `private static final int[]`, `public static final int[] EMPTY = new int[0];`, `public static final List<String> X = List.of(...)`, `public static readonly IReadOnlyList<string>`, `Array.Empty<int>()`, methods returning arrays, comments, strings and test files.

## Remediation

1. Make the array `private` and expose an unmodifiable view (`Collections.unmodifiableList(Arrays.asList(...))`, `List.of(...)`) or return a defensive copy (`ARRAY.clone()`).
2. In C#, expose `IReadOnlyList<T>` or `ImmutableArray<T>` instead of `T[]`.
