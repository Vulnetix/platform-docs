## Overview

VNX-425 maps to [CWE-425: Direct Request ('Forced Browsing')](https://cwe.mitre.org/data/definitions/425.html). An administrative page that is merely unlinked is not protected: anyone who guesses or reads its URL can request it directly. This rule reports admin routes that are registered without any authentication or authorisation check.

Reported:

- **JavaScript and TypeScript (Express-style):** `app`/`router` `.get/.post/.put/.patch/.delete/.all` whose only argument after the path is the handler (the path may be on the line after an open call), unless an inline handler checks `req.user`/`req.session` or compares a role (`role === ...`, `roles.includes(...)`, `hasRole`), only redirects, or the file mounts authentication middleware with `.use()` globally or on a prefix of the path.
- **Go:** `HandleFunc`/`Handle` and gin/echo/chi `GET`/`POST`/... with a bare handler name, in a file with no `.Use(` middleware, when the handler is defined in the same file and does not check authentication in its first 15 lines.

## What Gets Flagged

```javascript
app.get('/admin/users', adminController.listUsers)   // FLAGGED
manageRouter.delete(                                     // FLAGGED: path on the next line
  '/administrator/cache', (req, res) => { purgeCache(); res.end(); });
```

```go
http.HandleFunc("/admin/dashboard", adminDashboard)   // FLAGGED
```

## What Is Not Flagged

- Routes whose path is not administrative.
- Routes with middleware (`app.get('/admin', isLoggedIn, isAdmin, h)`) or a check on the user inside the handler. Writing a role (`{ role: 'admin' }`) is not a check.
- Files that mount auth middleware globally (`router.use(passport.authenticate('jwt'))`) or on the route's prefix.
- Go handlers wrapped in a call (`requireAdmin(h)`) or defined in another file.
- NestJS controllers and Spring endpoints, whose guards usually live elsewhere.
- Route calls inside string literals, test files and comments.

Reported by other rules, so one route is one finding:

- An administrative Flask, FastAPI or Quart route with nothing in front of it is reported by [VNX-306](/sast/rules/vnx-306/).
- A Spring or JAX-RS handler that `@PermitAll` opens to everyone is reported by [VNX-935](/sast/rules/vnx-935/).

## Remediation

Put every administrative route behind a check that the caller is an authenticated administrator:

```javascript
app.get('/admin/users', isLoggedIn, isAdmin, adminController.listUsers)
```
