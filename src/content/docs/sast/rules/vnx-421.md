## Overview

VNX-421 maps to [CWE-421: Race Condition During Access to Alternate Channel](https://cwe.mitre.org/data/definitions/421.html). A service that opens a local side channel for its own clients (a control socket, a FIFO, a named pipe) races every other local user for that channel's name. If the name lives somewhere anyone can create files, the attacker creates it first: the service fails to bind, or its clients connect to the attacker's endpoint and hand it their requests.

Reported:

- **C and C++:** `mkfifo`, `mkfifoat` and `mknod`, and a `sockaddr_un.sun_path` filled by `strcpy`, `strncpy`, `strlcpy`, `snprintf`, `memcpy` or a designated initializer, with a fixed path under `/tmp`, `/var/tmp` or `/dev/shm`, written as a literal, a `#define` or a constant.
- **Go:** `net.Listen`/`net.ListenPacket("unix", ...)`, `net.UnixAddr{Name: ...}`, `net.ResolveUnixAddr` and `syscall.Mkfifo`/`unix.Mkfifo` with such a path, including `filepath.Join("/tmp", ...)` and `filepath.Join(os.TempDir(), ...)`.
- **Python:** `os.mkfifo`, socket `.bind` in a file using `AF_UNIX`, `asyncio.start_unix_server`/`create_unix_server` and `socketserver.UnixStreamServer`/`UnixDatagramServer` with such a path, including `os.path.join(tempfile.gettempdir(), ...)`.
- **Windows named pipes:** `CreateNamedPipe`, `CreateNamedPipeA` and `CreateNamedPipeW` in a file that never passes `FILE_FLAG_FIRST_PIPE_INSTANCE`.

## What gets flagged

```c
strncpy(addr.sun_path, "/tmp/backupd.sock", sizeof(addr.sun_path) - 1);   // FLAGGED
```

```go
const ctlSocket = "/tmp/agent.sock"
ln, err := net.Listen("unix", ctlSocket)   // FLAGGED
```

```python
server = await asyncio.start_unix_server(handler, path="/tmp/agent-async.sock")   # FLAGGED
```

## What is not flagged

- Sockets and FIFOs in a directory only the service can write: `/run/<service>/`, `$XDG_RUNTIME_DIR`, a `mkdtemp()` or `os.MkdirTemp` result.
- Client-side connects (`net.Dial("unix", ...)`, `socket.connect(...)`).
- Paths computed only at run time, test files, comments and string literals that are not passed to these calls.
- `CreateNamedPipe` in a file that creates the first instance with `FILE_FLAG_FIRST_PIPE_INSTANCE`.

## Remediation

Create the channel inside a directory the service owns and others cannot write:

```c
mkdir("/run/backupd", 0700);
strncpy(addr.sun_path, "/run/backupd/control.sock", sizeof(addr.sun_path) - 1);
```

On Windows, create the first pipe instance with `FILE_FLAG_FIRST_PIPE_INSTANCE`, so the call fails if someone else already owns the name.
