## Overview

A call that reports failure only through its return value fails silently when that value is dropped: a short write goes unnoticed, a NULL pointer is dereferenced, or a failed privilege drop leaves the process running privileged. This maps to [CWE-252: Unchecked Return Value](https://cwe.mitre.org/data/definitions/252.html).

## What Gets Flagged

- Go: a bare statement `recv.Write(...)`, `recv.Read(...)` or `recv.WriteString(...)`, or a bare `io.Copy`, `io.CopyN`, `io.CopyBuffer`, `io.WriteString`, `io.ReadFull`, `io.ReadAtLeast`, `os.WriteFile` or `ioutil.WriteFile` call.
- C/C++: `malloc`, `calloc`, `realloc`, `strdup`, `strndup`, `fopen`, `fdopen` or `tmpfile` assigned to a variable that none of the next six code lines tests.
- C/C++: a bare `setuid`, `setgid`, `seteuid`, `setegid`, `setreuid`, `setregid`, `setresuid`, `setresgid`, `setgroups`, `initgroups` or `chroot` statement.

```go
conn.Write(frame)                         // flagged
io.Copy(out, src)                         // flagged
os.WriteFile(path, data, 0o600)           // flagged
```

```c
char *copy = malloc(n + 1);               /* flagged: used without a NULL check */
memcpy(copy, name, n);
setuid(uid);                              /* flagged */
```

Not flagged in Go: an explicit discard (`_ = f.Close()`, `_, _ = w.Write(b)`), a deferred, returned or assigned result, writes to writers that cannot fail (`bytes.Buffer`, `strings.Builder`, `bufio.Writer`, hashes and HMACs, `tabwriter`) and to an `http.ResponseWriter`, and test files. Not flagged in C: a test on the same line or in the next lines (`== NULL`, `!p`, `if (p)`, `assert(p)`, `serverAssert(p)`), abort-on-failure wrappers such as `xmalloc`/`zmalloc`, a `(void)` cast, comments and strings.

## Remediation

```go
if _, err := conn.Write(frame); err != nil {
	return err
}
```

```c
char *copy = malloc(n + 1);
if (copy == NULL)
    return NULL;
if (setuid(uid) != 0)
    abort();
```
