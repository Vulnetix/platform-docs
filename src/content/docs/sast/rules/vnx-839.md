## Overview

VNX-839 maps to [CWE-839: Numeric Range Comparison Without Minimum Check](https://cwe.mitre.org/data/definitions/839.html). `if (idx < size)` is only half a bounds check when `idx` is signed. A negative number satisfies it, and then indexes from the end of a Python list, throws in Java, or reads and writes before the start of a C array.

The rule follows a value read from untrusted input (Python `int()` of `request.*`, `sys.argv` or `input()`; Java `Integer.parseInt`/`valueOf` or `Long.parseLong` of `getParameter()`/`getHeader()` or of a variable assigned from one just above, `Scanner.nextInt()`; C/C++ `atoi`/`atol`/`strtol`, `std::stoi`/`stol`, or `sscanf` with `%d` into a signed variable). It reports the comparison when the value is checked against an upper bound within six lines, then used as an index (or, in Java, passed to `List.get`) within eight lines of the check, with no lower-bound check in between.

## What gets flagged

```python
idx = int(request.args.get("i", "0"))
if idx < len(ITEMS):          # FLAGGED: idx = -1 returns the last item
    return ITEMS[idx]
```

```c
int idx = atoi(arg);
if (idx >= 16)                /* FLAGGED: idx = -5 writes before names[] */
    return -1;
names[idx] = value;
```

## What is not flagged

- Range checks that also test the minimum: `0 <= i < n`, `i < 0 || i >= n`, `i >= 0 && i < n`.
- Values clamped with `max(0, ...)`, `Math.max(0, ...)` or `abs()`, or validated with `isdigit()`.
- `unsigned`/`size_t` variables and `strtoul`, constants, and values compared but never used as an index.

## Remediation

Check both ends of the range, or parse into an unsigned type:

```python
if not 0 <= idx < len(ITEMS):
    abort(404)
```
