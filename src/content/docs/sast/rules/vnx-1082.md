## Overview

VNX-1082 maps to [CWE-1082: Class Instance Self Destruction Control Element](https://cwe.mitre.org/data/definitions/1082.html). A C++ member function that destroys the object it runs on: `delete this;` or an explicit call of its own destructor.

## Why this matters

After `delete this` or `this->~T()`, any use of the object, by the rest of the method or by a caller still holding a pointer or reference to it, is a use after free. `delete this` on an object that was not allocated with plain `new` (on the stack, as a member, in an array, or by placement new) is undefined behaviour.

## What gets flagged

```cpp
void Connection::close() {
    ::close(socket_);
    delete this;                         // FLAGGED
}

void Session::reset() {
    this->~Session();                    // FLAGGED
    new (this) Session();
}

void Release() {
    if (--refs_ == 0) delete this;       // FLAGGED: intrusive refcount, same construct
}
```

Also reported: `delete (this);`, `delete static_cast<Derived*>(this);` and `std::destroy_at(this);`.

Intrusive reference counting is reported because it is the same construct; review that such objects are always heap-allocated and never touched after the final release.

## What does not get flagged

- Deleting another object or a member: `delete this->header_;`, `delete other;`, `delete[] data_;`.
- Destroying a different object explicitly, as an object pool does: `item->~Item();`.
- Destructor definitions (`Buffer::~Buffer()`).
- The text inside comments and string literals.
- Java, Python and other managed languages, which have no self-destruction construct.

## Remediation

1. Give ownership to the caller or a container: return the object to its owner, or hold it in `std::unique_ptr`/`std::shared_ptr` and let the owner release it.
2. If self-deletion is unavoidable (reference counting), make the destructor private or protected so the object can only be created with `new`, and return immediately after `delete this`.
3. For a confirmed false positive, add `// vulnetix-ignore: VNX-1082` on the line.
