## Overview

VNX-940 maps to [CWE-940: Improper Verification of Source of a Communication Channel](https://cwe.mitre.org/data/definitions/940.html). A window `message` event can be sent by any page that frames or opens this one. A handler that acts on `event.data` without checking `event.origin` takes commands from any site.

## What Gets Flagged

```javascript
window.addEventListener('message', function (event) {   // flagged
  document.getElementById('out').innerHTML = event.data.html;
});

window.addEventListener("message", receive, false);      // flagged when receive() never reads origin
window.onmessage = function (e) { ... };                 // flagged
```

Not flagged: a handler that reads `event.origin` (or a destructured `{ origin }`) or compares `event.source`; a named handler the file does not define; message events of Workers, WebSockets, MessagePorts, BroadcastChannels, Node child processes and worker scripts (`self.addEventListener`); comments and string literals. VNX-NODE-024 reports the same listener shape alongside wildcard `postMessage` targets.

## Remediation

```javascript
window.addEventListener('message', (event) => {
  if (event.origin !== 'https://app.example.com') return;
  handle(event.data);
});
```
