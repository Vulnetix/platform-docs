## Overview

VNX-266 maps to [CWE-266: Incorrect Privilege Assignment](https://cwe.mitre.org/data/definitions/266.html). It reports two ways code hands out root: making root the process's permanent identity, and marking a file set-user-ID or set-group-ID so that anyone who runs it gets its owner's privileges.

## Why this matters

`setuid(0)` in a process whose effective user is root sets the real, effective and saved user IDs to root at once. From then on there is no unprivileged identity left to return to, and every file the process opens, every command it runs and every child it starts runs as root. A set-user-ID bit does the same for a file: every user who can execute it runs it as the owner, so any flaw in it (an environment variable it trusts, a path it builds) becomes a local privilege escalation.

## What gets flagged

```c
if (setuid(0) != 0) { perror("setuid"); return 1; }
::setresuid(0, 0, 0);
chmod(dst, 04755);
fchmod(fd, S_ISUID | S_IRWXU | S_IRGRP | S_IXGRP | S_IROTH | S_IXOTH);
```

```python
os.setuid(0)
os.chmod(path, 0o4755)
os.chmod(path, st.st_mode | stat.S_ISUID)
```

Not flagged: a temporary `seteuid(0)` (whether it is lowered again is [VNX-272](/sast/rules/vnx-272/)); a function that also drops to a non-root user, including the `if (setuid(0) != -1)` check that confirms a drop cannot be undone; testing or clearing the bits (`st.st_mode & S_ISUID`, `mode & ~S_ISUID`); ordinary modes such as `0755`; wrappers like `my_setuid(0)`; and the calls in comments or string literals.

## Remediation

1. Do the privileged step with a temporary `seteuid(0)`, then drop permanently with `setgroups`, `setgid` and `setuid` to an unprivileged user.
2. Instead of a set-user-ID binary, grant the one capability the program needs (`setcap cap_net_bind_service+ep`) or move the privileged operation into a small helper behind a fixed, validated interface (polkit, a systemd service, a socket-activated daemon).

## Suppressing this rule

Put a `nosec` comment on the line, or on line 1 to cover the whole file. Use the comment marker of the file's language (`#`, `//`, `--` or `;`):

```text
# nosec vnx-266
// nosec vnx-266
```

Or record an ignore rule: `vulnetix ignore add --rule vnx-266 --reason "..."`. See [Suppressing findings](/sast/guides/suppressing-findings/).
