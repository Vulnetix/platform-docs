## Overview

VNX-124 maps to [CWE-124: Buffer Underwrite ('Buffer Underflow')](https://cwe.mitre.org/data/definitions/124.html). It reports:

1. `buf[strlen(buf) - 1] = ...` with no check that the string is non-empty (the `fgets` newline-strip idiom: an empty line writes `buf[-1]`).
2. `buf[len - 1] = ...` where `len` was assigned from `strlen()` a few lines above and is never compared before the write.
3. `buf[n] = '\0'` (or `buf[n - 1]`) where `n` is the return value of `read()`, `recv()`, `recvfrom()`, `recvmsg()`, `pread()` or `readlink()`, which is -1 on error, and `n` is never compared before the write.
4. A write through a literal negative index into an array declared in the same function.

## What Gets Flagged

```c
fgets(buf, size, stdin);
buf[strlen(buf) - 1] = '\0';                       // FLAGGED

ssize_t len = readlink(path, target, sizeof(target) - 1);
target[len] = 0;                                   // FLAGGED: len may be -1

size_t n = strlen(s);
s[n - 1] = 0;                                      // FLAGGED: n may be 0
```

## What Is Not Flagged

- Guarded writes: `if (len > 0 && buf[len - 1] == '\n')`, `if (*s && ...)`, `if (n < 0) return;`, `while ((r = read(...)) > 0)`.
- Reads such as `s[n - 1] == '\n'`, and `s[strcspn(s, "\n")] = '\0'`.
- Negative indexes on pointers into the middle of an allocation (sds-style string headers).

## Remediation

Check that a length is greater than zero, and that a read returned a non-negative count, before using it to index a write. Strip newlines with `s[strcspn(s, "\n")] = '\0'`.
