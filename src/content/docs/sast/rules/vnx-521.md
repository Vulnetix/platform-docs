## Overview

VNX-521 maps to [CWE-521: Weak Password Requirements](https://cwe.mitre.org/data/definitions/521.html). NIST SP 800-63B and OWASP ASVS 2.1.1 require passwords of at least 8 characters. The rule reports a minimum between 2 and 7 written into code:

- a length comparison on a password-named value: `len(password) < 6`, `password.length < 6`, `password.length() < 6`, `password.Length < 6`;
- a minimum declared on a password field: Joi/zod/yup `.min(N)`, express-validator `isLength({ min: N })`, jQuery Validate or Mongoose `minlength` under a password key, Java `@Size`/`@Length(min = N)` on a password field, ASP.NET Identity `options.Password.RequiredLength = N`, Django `MinimumLengthValidator` `min_length`;
- a Django `AUTH_PASSWORD_VALIDATORS = []`, which disables every check.

## What Gets Flagged

```python
if len(password) < 6:                                  # FLAGGED
    raise forms.ValidationError("Password too short")
```

```javascript
password: Joi.string().min(4).required(),              // FLAGGED
body("password").isLength({ min: 5 }),                 // FLAGGED
```

```java
@Size(min = 4, max = 64)                               // FLAGGED
private String password;
```

```csharp
[StringLength(64, MinimumLength = 6)]                  // FLAGGED
[DataType(DataType.Password)]
public string Password { get; set; }
```

## What Is Not Flagged

Minimums of 8 or more, a minimum of 0 or 1 (a presence check such as `z.string().min(1, "Password is required")` on a login form), maximum-length checks (`password.length() > 30`), minimums on other fields, the numbers inside messages, comments, strings, minified files and test code. Policies configured outside the code (an identity provider, a directory) are not seen.

## Remediation

1. Require at least 8 characters (12 or more is better) and allow long passphrases (at least 64 characters).
2. Check new passwords against a list of breached and common passwords.
3. For Django, keep `MinimumLengthValidator` (with `min_length` of 8 or more) and `CommonPasswordValidator` in `AUTH_PASSWORD_VALIDATORS`.
