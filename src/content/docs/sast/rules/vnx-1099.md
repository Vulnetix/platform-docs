## Overview

VNX-1099 maps to [CWE-1099: Inconsistent Naming Conventions for Identifiers](https://cwe.mitre.org/data/definitions/1099.html). It reports the second of two function or method definitions in the same scope of one file whose names are the same words in different conventions, one snake_case and one camelCase: `get_user` and `getUser`, `check_session` and `checkSession`.

## Why This Matters

The name no longer tells a caller which function it gets. In practice the two variants drift apart: one validates and the other does not, or a security fix lands in one and is missed in the other. A caller who types the convention they are used to gets whichever variant happens to use it.

Not reported: names that differ only by leading or trailing underscores (`_fetch` beside `fetch`), deliberate compatibility aliases whose body calls the other name, functions in different scopes (including methods of two separate classes), names that differ in more than convention, bundled third-party JavaScript, test files and comments. Mixing conventions across files, or in variables and classes, is not judged.

## What Gets Flagged

```python
def validate_token(token, secret):
    return hmac.compare_digest(token, sign(secret))

def validateToken(token, secret):        # FLAGGED
    return token == sign(secret)
```

```javascript
export function checkSession(req) { ... }
function check_session(req) { ... }      // FLAGGED
```

## Remediation

1. Keep one function and one name; update callers.
2. If an alias is needed for compatibility, make it a one-line call to the real implementation and mark it deprecated.
3. For a confirmed false positive, add a `vulnetix-ignore: VNX-1099` comment on the line.

## Suppressing this rule

Put a `nosec` comment on the line, or on line 1 to cover the whole file. Use the comment marker of the file's language (`#`, `//`, `--` or `;`):

```text
# nosec vnx-1099
// nosec vnx-1099
```

Or record an ignore rule: `vulnetix ignore add --rule vnx-1099 --reason "..."`. See [Suppressing findings](/sast/guides/suppressing-findings/).
