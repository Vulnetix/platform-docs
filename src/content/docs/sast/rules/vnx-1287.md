## Overview

VNX-1287 maps to [CWE-1287: Improper Validation of Specified Type of Input](https://cwe.mitre.org/data/definitions/1287.html). Express's query parser turns `?q[]=a` into an array and `?q[x]=1` into an object, and a JSON body field can be any JSON type. Code that treats such a value as a string either throws (a crash or a 500) or, for `length`, `includes`, `indexOf` and `startsWith` checks, gets an answer for an array and lets the request past the check.

Reported:

- **JavaScript/TypeScript**: a string method (`toLowerCase`, `trim`, `split`, `startsWith`, `endsWith`, `includes`, `indexOf`, `replace`, `match`, `search`, `slice`, `substring`, `concat`, `repeat` and others) or `.length` on a field of `req.query`, `req.body`, `request.body`, `ctx.query` or `ctx.request.body`, directly or through a variable or destructured name assigned from it in the 10 lines above.
The same weakness in Python, a `str` method on a field of a JSON body (`request.json`, `request.get_json()`, DRF `request.data`, `json.loads(request.body)`), is reported by [VNX-241](/sast/rules/vnx-241/), and this rule does not report it a second time.

Not reported: route params (always strings); values checked with `typeof` or `Array.isArray`, or coerced with `String()`; files that use express-validator, Joi, zod, yup, celebrate, ajv, class-validator or superstruct; comments and strings.

## What gets flagged

```javascript
if (req.body.email.length !== 0 && req.body.password.length !== 0) {   // FLAGGED
  req.body.email = req.body.email.trim();                               // FLAGGED
}
```

```typescript
const { tags } = req.query;
const list = tags.split(',');                                           // FLAGGED: ?tags[]=a is an array
```

## What is not flagged

```javascript
const q = req.query.q;
if (typeof q !== 'string') return res.status(400).end();
const term = q.toLowerCase();
```

## Remediation

1. Check the type (`typeof value === 'string'`) before using a request value as a string.
2. Validate request bodies and query strings against a schema.
3. In Express, consider `app.set('query parser', 'simple')` so query values are never arrays or objects.
