## Overview

VNX-673 maps to [CWE-673: External Influence of Sphere Definition](https://cwe.mitre.org/data/definitions/673.html). A chroot jail, the module import path and the program and library search paths all define the boundary of what a process trusts. When a remote party chooses that boundary, it can point the jail at `/`, import its own module, or load its own shared library.

Reported, when the value comes from an HTTP request (Flask, Django, DRF, aiohttp `request.args`/`form`/`values`/`json`/`data`/`get_json()`/`GET`/`POST`/`query_params`/`match_info`/`params`/`body`/`cookies`/`headers`, Tornado `self.get_argument`) or a socket `recv`, on the sink line or through a variable assigned in the 10 lines above:

- `os.chroot(...)`
- `sys.path.insert(...)`, `sys.path.append(...)`, `site.addsitedir(...)`
- `os.environ["PATH" | "PYTHONPATH" | "PYTHONHOME" | "LD_LIBRARY_PATH" | "LD_PRELOAD" | "DYLD_*"] = ...` and `os.putenv` of the same.

## What Gets Flagged

```python
root = request.args.get("dir")
os.chroot(root)                      # FLAGGED
```

```python
plugin_dir = request.GET.get("plugin_dir")
sys.path.insert(0, plugin_dir)       # FLAGGED
```

```python
os.environ["LD_LIBRARY_PATH"] = request.json.get("libdir")   # FLAGGED
```

```python
env = os.environ.copy()
env["LD_LIBRARY_PATH"] = request.form["libdir"]   # FLAGGED: handed to subprocess.run(env=env)
```

## What Is Not Flagged

- Constants, settings and configuration values, paths built from `__file__` or `BASE_DIR`.
- Command-line arguments (`sys.argv`, argparse): the operator chooses those, not a remote actor.
- A request value first mapped through an allow-list into a different variable.
- Other environment variables, comments, string literals and triple-quoted strings.

## Remediation

Never let a request name a path the process trusts. Map the request to a fixed set of server-side values:

```python
JAILS = {"a": "/srv/jails/a", "b": "/srv/jails/b"}
os.chroot(JAILS[request.args["name"]])
```
