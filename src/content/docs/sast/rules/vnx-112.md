## Overview

VNX-112 maps to [CWE-112: Missing XML Validation](https://cwe.mitre.org/data/definitions/112.html). It reports an XML parse whose input is the request body or a request value, used directly or through a variable assigned from it in the 25 lines above, in a file whose code never validates the document:

- Java `DocumentBuilder`/`SAXParser`/`XMLReader` `.parse`, JAXB `.unmarshal`, StAX `createXMLStreamReader`/`createXMLEventReader`
- Python lxml/ElementTree/defusedxml `fromstring`/`XML`/`parse`, `minidom.parseString`, `xmltodict.parse`, `untangle`
- Node `xml2js` `parseString`/`parseStringPromise`, `libxmljs` `parseXml`/`parseXmlString`, `DOMParser.parseFromString`, `xml-js`, fast-xml-parser `XMLParser.parse`

A file that mentions schema validation in code (`setSchema`, `SchemaFactory`, `Validator`, `.validate(`, `setValidating(true)`, `XMLSchema`, `schema=`, an XSD, or a schema check of the parsed result) is not reported, nor is XML read from files or constants. External-entity (XXE) handling is a separate weakness with its own rules.

## Why This Matters

Code that reads `doc.getElementsByTagName("qty").item(0)` assumes the element exists, appears once and holds a number. Without validation the requester decides all of that: missing or repeated elements, unexpected types and oversized content reach business logic, causing crashes, logic bypasses (a second `<price>` element read by one component and ignored by another) and injection further downstream.

## What Gets Flagged

```java
Document doc = db.parse(request.getInputStream());                 // FLAGGED
Order order = (Order) u.unmarshal(new StringReader(body));         // FLAGGED (@RequestBody String body)
```

```python
root = etree.fromstring(request.data, parser)                      # FLAGGED
doc = minidom.parseString(request.body)                            # FLAGGED
```

```javascript
xml2js.parseString(req.body, (err, result) => { /* ... */ });      // FLAGGED
const doc = parser.parse(req.body as string);                      // FLAGGED (fast-xml-parser)
```

Not flagged: `dbf.setSchema(schema)` in the same file, `etree.XMLParser(schema=SCHEMA)`, a Joi `feedSchema.validate(result)` of the parsed document, `ET.parse("config/settings.xml")`.

## Remediation

1. Validate request XML against an XSD before using it: `DocumentBuilderFactory.setSchema()`/`Unmarshaller.setSchema()` in Java, `etree.XMLParser(schema=...)` or `XMLSchema.assertValid()` in lxml, `doc.validate(xsd)` in libxmljs.
2. Or validate the parsed structure with a schema library (Joi, ajv, pydantic) before reading fields from it.
3. Reject documents that fail validation with a 400 response; never fall back to using them.
