## Overview

VNX-186 maps to [CWE-186: Overly Restrictive Regular Expression](https://cwe.mitre.org/data/definitions/186.html). A filter that is meant to catch a dangerous value but only matches one spelling of it lets every other spelling through. The rule reports denylists for script, markup and SQL injection tokens that are matched case-sensitively: HTML, JavaScript URLs and SQL keywords are all case-insensitive, so `<SCRIPT>`, `JaVaScRiPt:` and `UNION SELECT` pass a filter written for the lower-case form.

## What gets flagged

A pattern or literal naming `<script`, `</script`, `javascript:`, `vbscript:`, `onerror`, `onload`, `onmouseover`, `<iframe`, `<svg`, `<img`, `<object`, `<embed`, `union`, `drop table`, `sleep(` or `benchmark(`, used as:

- a removal with an empty replacement (`.replace`, `.replaceAll`, `.gsub`, `.sub`, `.delete`, `str_replace`);
- a regular expression with no case-insensitive flag (`re.sub`/`re.search`/`re.compile` without `re.I`, a JavaScript or Ruby `/.../` literal or `new RegExp` without `i`, `Pattern.compile` without `CASE_INSENSITIVE`, `preg_replace`/`preg_match` without the `i` modifier);
- a membership test of a bare token (`"<script" in value`, `.includes("<script")`, `.contains("union select")`, `strpos($s, "<script")`).

```python
name = name.replace("<script>", "").replace("</script>", "")      # flagged
comment = re.sub(r"<script.*?>.*?</script>", "", request.form["c"])  # flagged
```

```php
$name = str_replace('<script>', '', $name);                          // flagged
$msg = preg_replace('/<script(.*?)>/', '', $_POST['msg']);            // flagged
```

```javascript
return html.replace(/<script\b[^>]*>[\s\S]*?<\/script>/g, '');      // flagged
return !/^javascript:/.test(u);                                       // flagged
```

Not flagged: `(?i)`, `re.I`/`re.IGNORECASE`, the `i` flag, `Pattern.CASE_INSENSITIVE`, `str_ireplace`/`stripos`, a subject lower-cased first (`value.lower()`), a replacement that inserts content (template assembly), regex extraction (`.match`, `.exec`, `findall`), a check for one exact payload, test code, minified files and comments.

## Remediation

1. Encode output for its context (HTML-escape, attribute-escape, URL-encode) or use a vetted sanitiser such as DOMPurify, bleach or OWASP Java HTML Sanitizer, instead of stripping tokens.
2. For SQL, use parameterised queries; never filter keywords.
3. If a denylist must stay as defence in depth, match case-insensitively and loop until the input stops changing.

```python
import html
safe = html.escape(request.args.get("name", ""))
```
