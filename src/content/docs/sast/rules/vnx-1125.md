## Overview

VNX-1125 maps to [CWE-1125: Excessive Attack Surface](https://cwe.mitre.org/data/definitions/1125.html). Most attack surface is intended: a web route is an endpoint someone chose to publish. This rule reports the configurations where a Python remote-procedure server publishes **far more than the functions it was written to serve**:

- XML-RPC `register_instance(obj, allow_dotted_names=True)` (or `True` as the second argument): every attribute reachable through dotted names, including module globals, is callable remotely, a documented route to code execution;
- RPyC `ThreadedServer` / `ForkingServer` / `ThreadPoolServer` / `OneShotServer` serving `SlaveService`, `ClassicService` or `MasterService`: the whole Python runtime of the process is remote-callable;
- RPyC protocol settings `allow_all_attrs`, `allow_setattr` or `allow_delattr` set to `True`;
- Pyro4 `config.REQUIRE_EXPOSE = False`: every method of every registered object becomes remote-callable;
- `register_function(eval)`, `exec`, `compile`, `__import__`, `open`, `os.system`, `os.popen` or a `subprocess` function registered as a remote procedure.

Not reported: `register_instance` without dotted names, custom `rpyc.Service` subclasses with `exposed_` methods, Pyro objects marked `@expose`, `register_function` of the application's own handlers, web routes, comments, strings and test files.

## What Gets Flagged

```python
server.register_instance(Inventory(), allow_dotted_names=True)   # FLAGGED
t = ThreadedServer(SlaveService, hostname="0.0.0.0", port=18812)  # FLAGGED
Pyro4.config.REQUIRE_EXPOSE = False                               # FLAGGED
server.register_function(os.system, "run")                        # FLAGGED
```

```python
class CalcService(rpyc.Service):          # NOT FLAGGED: only exposed_ methods
    def exposed_add(self, a, b):
        return a + b

server.register_instance(Calculator())    # NOT FLAGGED
```

## Remediation

1. Register only the functions clients need, by name, with `register_function`; never pass `allow_dotted_names=True`.
2. Serve a custom `rpyc.Service` that defines `exposed_` methods instead of the classic service, and leave `allow_all_attrs`, `allow_setattr` and `allow_delattr` at their defaults.
3. Keep Pyro's `REQUIRE_EXPOSE` on and mark remote methods with `@Pyro4.expose`.
4. Bind RPC servers to localhost or a private interface and require authentication.
