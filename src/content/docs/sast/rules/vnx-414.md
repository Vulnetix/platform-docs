## Overview

VNX-414 maps to [CWE-414: Missing Lock Check](https://cwe.mitre.org/data/definitions/414.html). A lock call that can fail without blocking tells the caller whether it got the lock. When that answer is thrown away, the code that follows runs whether or not the lock is held, and two threads or processes update the same state at once.

The rule reports the attempt when it is a whole statement, its result not assigned, returned, tested or passed on:

| Language | Calls |
|---|---|
| C, C++ | `pthread_mutex_trylock`, `pthread_rwlock_tryrdlock`/`trywrlock`, `pthread_spin_trylock`, `mtx_trylock`, `sem_trywait`, `pthread_mutex_timedlock`, `sem_timedwait`, `flock(fd, LOCK_EX/LOCK_SH \| LOCK_NB)`, `lockf(fd, F_TLOCK, ...)`, `fcntl(fd, F_SETLK, ...)` |
| C++ | `m.try_lock()`, `try_lock_for`, `try_lock_until`, `std::try_lock(a, b)`; a `std::unique_lock` built with `std::try_to_lock` whose `owns_lock()` (or the lock itself) is not tested in the next 10 lines |
| Go | `mu.TryLock()`, `rw.TryRLock()` |
| Java | `lock.tryLock(...)`, `channel.tryLock(...)` |
| Python | `lock.acquire(False)`, `acquire(blocking=False)`, `acquire(block=False)` (multiprocessing), `acquire` with a finite timeout (a negative or `None` timeout waits forever and is not reported) |

## What Gets Flagged

```c
pthread_mutex_trylock(&stats_lock);   // FLAGGED: may not hold the lock
s->hits++;
```

```go
c.mu.TryLock()                        // FLAGGED
c.data[k] = v
```

```python
self.lock.acquire(blocking=False)     # FLAGGED
self.active += 1
```

## What Is Not Flagged

- Results that are tested, assigned or returned: `if (pthread_mutex_trylock(&m) != 0) return;`, `if !mu.TryLock() {`, `got = lock.acquire(False)`.
- An explicit discard: `(void)pthread_mutex_trylock(&m)` in C, `_ = mu.TryLock()` in Go.
- Blocking locks (`pthread_mutex_lock`, `flock` without `LOCK_NB`, `fcntl(F_SETLKW)`, `Lock()`), unlocks (`LOCK_UN`), test files, comments and string literals.

## Remediation

Proceed only when the attempt succeeded:

```c
if (pthread_mutex_trylock(&stats_lock) != 0)
    return;     /* busy: try again later */
s->hits++;
pthread_mutex_unlock(&stats_lock);
```
