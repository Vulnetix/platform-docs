## Overview

VNX-437 maps to [CWE-437: Incomplete Model of Endpoint Features](https://cwe.mitre.org/data/definitions/437.html). The check and the HTTP client or browser disagree about which host a URL names. A string check does not know about userinfo, subdomains or query strings, so `https://trusted.example.com.evil.net`, `https://trusted.example.com@evil.net` and `https://evil.net/?trusted.example.com` all pass it, and the request goes to the attacker (SSRF or open redirect).

## What gets flagged

The line that requests or redirects, when within fifteen lines above it the same variable was checked as a raw string against a host literal:

- `startsWith`/`startswith` with a scheme and host but no `/` after the host;
- `endsWith`/`endswith`, `includes`, `indexOf` or Python `in` with a host literal;
- a regular-expression literal whose pattern ends at the host, tested with `.test()` (`/^https:\/\/cdn\.acme\.com/.test(u)`).

Also, in Node, a request of the original string when the host, hostname, protocol or origin was vetted on the result of the legacy `url.parse()`, whether assigned, read inline (`url.parse(u).hostname`) or destructured (`const { hostname } = url.parse(u)`).

```javascript
if (!target.startsWith('https://cdn.acme-media.com')) return res.sendStatus(400);
const upstream = await fetch(target);                          // FLAGGED

const parsed = url.parse(hookUrl);
if (!ALLOWED.has(parsed.hostname)) throw new Error('denied');
https.request(hookUrl, { method: 'POST' });                    // FLAGGED
```

```python
if not url.startswith("https://api.partner-data.com/"):        # ends at "/": not flagged
    abort(400)
return requests.get(url, timeout=5)
```

Not reported: prefix checks that end at a path separator, checks on a parsed `new URL()`/`urlparse` hostname (including a re-parse between the raw check and the request), checks not followed by a request of the same variable, a positive check whose block does not contain the request, scheme-only checks, comments and strings. Request smuggling through a lenient HTTP parser is VNX-444.

## Remediation

1. Parse the URL once (`new URL()`, `urllib.parse.urlsplit`) and compare the hostname exactly against an allow-list.
2. Request the parsed URL, not the original string.
3. If a prefix check is unavoidable, end it with `/` after the host.
