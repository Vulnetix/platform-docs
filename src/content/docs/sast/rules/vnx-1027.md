## Overview

VNX-1027 maps to [CWE-1027: OWASP Top Ten 2017 Category A1 - Injection](https://cwe.mitre.org/data/definitions/1027.html). It covers the injection class that has no other rule: the module a Node.js process loads chosen by the request. It reports `require()`, `require.resolve()` and dynamic `import()` whose specifier contains Express/Koa request data (`req.query`, `req.body`, `req.params`, `req.headers`, `req.cookies`, `ctx.query`, `ctx.params`, `ctx.request.body`), directly, through a variable assigned or destructured from it a few lines above, or concatenated or interpolated into a path.

Not reported: constant specifiers, lookups through an object or `Map` (`require(PLUGINS[name])`), values checked against an allowlist (`includes`, `has`, `indexOf`, `switch`, `===`) in the lines between, comments and test files. Other A1 injection classes have their own rules: eval/Function/vm (VNX-913, VNX-94), child_process (VNX-NODE-003), SQL (VNX-NODE-007), NoSQL (VNX-NODE-014), templates (VNX-NODE-011).

## Why this matters

`require()` runs the file it loads. With a request-controlled specifier, `../../` traversal or an uploaded `.js` file turns the endpoint into remote code execution with the server's privileges.

## What gets flagged

```javascript
const plugin = require(req.query.name);
const renderer = require('./themes/' + theme);   // theme = req.body.theme
```

```typescript
const mod = await import(`./locales/${lang}.js`); // lang from req.headers
```

## Remediation

1. Map the request value through a fixed table of allowed modules: `const plugin = PLUGINS[req.query.name]`.
2. If the set is open-ended, validate the value against an explicit allowlist before loading anything.
