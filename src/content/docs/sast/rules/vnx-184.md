## Overview

VNX-184 maps to [CWE-184: Incomplete List of Disallowed Inputs](https://cwe.mitre.org/data/definitions/184.html). It reports a collection literal (Python list/tuple/set/dict, JavaScript array, Java `List.of`/`Arrays.asList`/`Set.of`, Go slice or map, PHP `array(...)`) whose entries are attack tokens, when either:

- the variable is named as a deny-list (`blacklist`, `denylist`, `blocklist`, `forbidden…`, `disallowed…`, `banned…`, `blocked…`, `dangerous…`, `unsafe…`, `bad…`, `…filter`) and holds at least one such token; or
- it holds two or more tokens of one family and the file applies it within 40 lines (`contains`, `includes`, `replace`, `str_replace(array_keys(...))`, `in`, a `for`/`range` loop).

The families are shell metacharacters (`;` `&&` `|` `||` `&` `` ` `` `$(` `>` `<`), script and HTML (`&lt;script`, `javascript:`, `onerror`, `onload`, `&lt;iframe`), traversal (`../`, `..\`, `/etc/passwd`) and SQL (`--`, `/*`, `'`, `union`, `select`, `drop`..., with at least one comment, quote or `union` token). Executable extensions (`.php`, `.exe`, `.jsp`, `.sh`...) count for a deny-named list.

Not reported: escaping tables (entries mapped to a non-empty replacement), allow-lists, deny-named lists of other values (IP addresses, user names), token lists the file never applies, test files, comments and string literals.

## Why this matters

A deny-list is a guess at every dangerous input. Removing `;` and `&&` leaves `|`, `||`, a newline and `$(...)`; rejecting `<script` leaves `<img onerror=...>`; rejecting `.php` leaves `.phtml` and `.PHP`. The attacker only needs the one the list forgot.

## What gets flagged

```php
// FLAGGED: removing two shell separators before shell_exec
$substitutions = array(
    '&&' => '',
    ';'  => '',
);
$target = str_replace(array_keys($substitutions), $substitutions, $target);
```

```java
// FLAGGED
private static final List<String> DENY_LIST = List.of(";", "&&", "|");
```

```go
// FLAGGED
var forbiddenExtensions = []string{".php", ".exe", ".sh"}
```

```python
# NOT FLAGGED: an escaping table and an IP block-list
HTML_ESCAPES = {"&": "&amp;", "<": "&lt;", ">": "&gt;"}
BLOCKED_IPS = ["10.0.0.1"]
```

## Remediation

1. Validate against an allow-list of what is permitted (a host-name pattern, a set of extensions, an enum of values).
2. Better still, use the API that removes the need to filter: an argument array instead of a shell string, a parameterised query, context-aware output encoding.
