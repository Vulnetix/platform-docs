## Overview

VNX-439 maps to [CWE-439: Behavioral Change in New Version or Environment](https://cwe.mitre.org/data/definitions/439.html). The same line of code is weak on one Python version and broken, or silently different, on another, so its security depends on the runtime it happens to be deployed on.

## What gets flagged

- `hmac.new()` or `hmac.HMAC()` with no `digestmod=` and fewer than three positional arguments: MD5 before Python 3.8, `TypeError` from 3.8.
- `ssl.SSLContext()` with no protocol, or with `ssl.PROTOCOL_TLS`/`PROTOCOL_SSLv23`: role and verification defaults vary by version (deprecated since 3.10).
- Module-level `ssl.wrap_socket()`: no certificate or hostname verification by default, removed in 3.12.
- `ssl.match_hostname()`: removed in 3.12.
- `cgi.escape()`: removed in 3.8, and leaves quotes unescaped by default.

From-imported names (`from ssl import wrap_socket`, `from cgi import escape`) are recognised.

```python
mac = hmac.new(SECRET, payload)                         # FLAGGED
ctx = ssl.SSLContext()                                  # FLAGGED
tls = ssl.wrap_socket(raw)                              # FLAGGED

mac = hmac.new(SECRET, payload, hashlib.sha256)         # not flagged
ctx = ssl.create_default_context()                      # not flagged
```

Not reported: `hmac.digest()`, `SSLContext(ssl.PROTOCOL_TLS_CLIENT)`/`PROTOCOL_TLS_SERVER`, `context.wrap_socket()`, `html.escape()`, comments and strings. Explicitly obsolete TLS versions are VNX-PY-021; tar extraction without a filter is VNX-409.

## Remediation

1. Always pass `digestmod` to `hmac.new()`.
2. Use `ssl.create_default_context()` or `SSLContext(ssl.PROTOCOL_TLS_CLIENT)` and wrap sockets through the context with `server_hostname=`.
3. Replace `cgi.escape()` with `html.escape()`.
