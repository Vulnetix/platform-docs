## Overview

VNX-287 maps to [CWE-287: Improper Authentication](https://cwe.mitre.org/data/definitions/287.html). A placeholder written during development ("SSO will replace this", "bcrypt is slow in dev") is shipped, and the function every login or request goes through accepts anything.

The rule reports, in production code (test and fixture paths are skipped):

- a function or method named for an authentication decision (`authenticate*`, `check/verify/validate` + `password`, `credentials`, `login`, `token`, `jwt`, `api_key`, `signature`, `otp`/`mfa`, `session`; Java `PasswordEncoder.matches`) whose first statement is `return True`/`return true`, including a one-line Java/JS body and an arrow function whose body is `true`;
- an Express-style authentication middleware (`requireAuth`, `ensureAuthenticated`, `isLoggedIn`, `checkJwt`, ...) taking `next` whose first statement is `next()`;
- a Python `login_required`/`requires_auth` decorator that returns the wrapped view unchanged.

## What Gets Flagged

```python
class PartnerBackend(BaseBackend):
    def authenticate(self, request, username=None, password=None):
        return True          # FLAGGED

def login_required(view):
    return view              # FLAGGED
```

```java
@Override
public boolean matches(CharSequence rawPassword, String encodedPassword) { return true; }  // FLAGGED
```

```js
const ensureAuthenticated = (req, res, next) => next();   // FLAGGED
```

## What Is Not Flagged

- Routines whose first statement is a check, a lookup or a returned verification (`return bcrypt.compare(...)`).
- User-model flags (`is_authenticated`, `is_active` properties) and authorisation predicates (`has_permission`, `supports`, `isEnabled`).
- Middleware not named for authentication, test and fixture code, comments and string literals.

## Remediation

Implement the real check, or fail closed until it exists:

```python
def authenticate(self, request, username=None, password=None):
    user = User.objects.filter(username=username).first()
    if user and user.check_password(password):
        return user
    return None
```
