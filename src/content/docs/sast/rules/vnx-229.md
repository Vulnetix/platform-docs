## Overview

VNX-229 maps to [CWE-229: Improper Handling of Values](https://cwe.mitre.org/data/definitions/229.html). It reports a request value converted to a number where a missing or malformed value is not handled:

- **Python:** `int()` or `float()` applied to a Flask, Django or DRF request value (`request.args`, `form`, `values`, `GET`, `POST`, `json`, `get_json()`, `data`, `cookies`, `headers`, `query_params`), inline or through a variable assigned from one in the eight lines above, outside any `try` block.
- **Node.js / TypeScript:** `parseInt()`, `parseFloat()` or `Number()` of `req.query` or `req.body` (inline, or through an assigned or destructured variable) whose result is neither defaulted on the same line (`||`, `??`) nor tested with `isNaN`, `Number.isNaN`, `isFinite` or `Number.isInteger` in the lines that follow.

## Why this matters

In Python a missing parameter raises `TypeError` and a non-numeric one `ValueError`, so any client can turn the endpoint into a 500; `float()` also accepts `"nan"` and `"inf"`, which then poison arithmetic such as balances and discounts. In JavaScript the conversion never fails: it yields `NaN`, which flows into queries and calculations.

Not reported: Flask's `get(..., type=int)`, a conversion inside `try` or `with contextlib.suppress(...)`, a value guarded by `isdigit()`/`isnumeric()`/`isdecimal()` or a regex match just above, route parameters (`req.params`, constrained by the route pattern), constants and environment values, commented-out code and string literals.

## What gets flagged

```python
src.balance -= int(request.form['amount'])

page = request.GET.get("page", 1)
offset = (int(page) - 1) * 20
```

```javascript
const limit = parseInt(req.query.limit, 10);
const items = await Item.find().limit(limit);
```

## Remediation

```python
page = request.args.get("page", 1, type=int)
try:
    amount = int(request.form["amount"])
except (TypeError, ValueError):
    abort(400)
```

```javascript
const limit = parseInt(req.query.limit, 10);
if (Number.isNaN(limit)) return res.status(400).send("bad limit");
```
