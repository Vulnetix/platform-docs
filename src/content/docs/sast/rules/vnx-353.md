## Overview

VNX-353 maps to [CWE-353: Missing Support for Integrity Check](https://cwe.mitre.org/data/definitions/353.html). It reports, in `.html`/`.htm` pages and template files (ERB, EJS, Handlebars, Mustache, Jinja/Django/Nunjucks/Twig/Liquid, JSP, Razor, PHP, Vue, Svelte, Go templates):

- a `<script>` whose `src` is an absolute `http(s)://` or protocol-relative `//` URL, and
- a `<link rel="stylesheet">` whose `href` is such a URL,

when the tag (which may span up to six lines) carries no `integrity=` attribute.

Not reported: tags with `integrity=`, same-origin and relative URLs, a URL built from a template expression, other `<link>` relations (`canonical`, `preconnect`, `icon`, `alternate`), anchors, HTML-escaped and commented-out tags, prose files, and endpoints whose content varies per request and cannot be pinned by a hash (Google Tag Manager/Analytics, reCAPTCHA, hCaptcha, Turnstile, Google Fonts and Bunny Fonts CSS, Google Maps/APIs/Sign-In, Stripe.js, Font Awesome kits, Facebook and Twitter widgets).

## Why This Matters

A script from a CDN runs with the full authority of your page: it can read the DOM, cookies not marked HttpOnly and form input. Without an integrity hash the browser runs whatever the CDN serves, so a compromised CDN account, a hijacked package version or (for `http://`) anyone on the network path can replace it.

## What Gets Flagged

```html
<!-- FLAGGED -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css">
<script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>
<script src="//ajax.googleapis.com/ajax/libs/angularjs/1.8.2/angular.min.js"></script>
```

```html
<!-- NOT FLAGGED -->
<script src="https://code.jquery.com/jquery-3.7.1.min.js"
        integrity="sha256-/JqT3SQfawRcv/BIHPThkBvs0OEvtFFmqPF/lYI/Cxo="
        crossorigin="anonymous"></script>
<script src="/static/js/app.js"></script>
```

## Remediation

1. Add `integrity="sha384-..."` and `crossorigin="anonymous"` to every third-party script and stylesheet; CDNs such as jsDelivr and cdnjs publish the hash.
2. Pin an exact version in the URL: a hash cannot be kept for `@latest` or a major-version range.
3. Better still, bundle or self-host the dependency so it ships with your own code.
4. Add a Content-Security-Policy `script-src` that lists the allowed origins.
