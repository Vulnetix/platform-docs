## Overview

VNX-419 maps to [CWE-419: Unprotected Primary Channel](https://cwe.mitre.org/data/definitions/419.html). An administration channel carries the most powerful credentials and commands a service accepts. Served in plaintext on a network interface, anyone on the path can read the admin's password or session and replay its commands.

Reported:

- **Go:** `http.ListenAndServe(addr, handler)` whose address or handler names an admin, management or mgmt interface; `X.ListenAndServe()` or `X.Serve(ln)` where `X` is so named, or is an `http.Server` literal whose `Addr` or `Handler` is; `net.Listen("tcp", addr)` with an admin address whose listener is not wrapped by `tls.NewListener`.
- **Java and Kotlin:** `new ServerSocket(...)`, `ServerSocketChannel.open().bind(...)` and `HttpServer.create(...)` whose variable, port or address names an admin or management interface.

## What Gets Flagged

```go
log.Fatal(http.ListenAndServe(":9090", adminMux))   // FLAGGED
```

```java
try (ServerSocket adminSocket = new ServerSocket(adminPort)) {   // FLAGGED
```

```kotlin
val managementServer = HttpServer.create(InetSocketAddress(config.managementPort), 0)   // FLAGGED
```

## What Is Not Flagged

- `ListenAndServeTLS`, `ServeTLS`, `tls.NewListener`, `SSLServerSocket`, `HttpsServer`.
- Listeners bound to `127.0.0.1`, `localhost`, `[::1]` or `InetAddress.getLoopbackAddress()`, and Unix sockets.
- Listeners that do not name an administrative interface (an `/admin` route on the public listener is [VNX-306](/sast/rules/vnx-306/)'s concern), test files and comments.

Whether the admin handler also requires authentication is not judged.

## Remediation

Serve the admin interface with TLS, or keep it off the network:

```go
log.Fatal(http.ListenAndServeTLS(":9443", certFile, keyFile, adminMux))
// or
log.Fatal(http.ListenAndServe("127.0.0.1:9090", adminMux))
```
