## Overview

VNX-622 maps to [CWE-622: Improper Validation of Function Hook Arguments](https://cwe.mitre.org/data/definitions/622.html). The general weakness has no static signature in application JavaScript, so this rule reports its most concrete server-side form: the client names the function the response will call (a JSONP callback), and the server writes that name into executable script unchecked. The caller then chooses what code runs in any page that loads the endpoint.

## What Gets Flagged

```javascript
res.send(req.query.callback + '(' + data + ');');
```

```typescript
const cb = req.query.cb as string
res.send(`${cb}(${payload})`)
```

```javascript
const callback = ctx.query.callback;
ctx.body = `${callback}(${JSON.stringify(stats)})`;
```

Not flagged: `res.jsonp()` (Express restricts the callback charset), a name sanitised with `.replace()` or checked with a regular expression before use, constant callback names, comments and string literals.

## Remediation

Use `res.jsonp()`, or allow only identifier characters:

```javascript
if (!/^[A-Za-z_$][\w$.]*$/.test(cb)) return res.status(400).end();
```
