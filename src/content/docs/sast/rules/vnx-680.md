## Overview

VNX-680 maps to [CWE-680: Integer Overflow to Buffer Overflow](https://cwe.mitre.org/data/definitions/680.html). An allocation size computed as `count * size` wraps when `count` is large, so `malloc` returns a small buffer and the loop that fills `count` elements writes far past it. The rule reports the allocation when the count comes from outside the program and nothing checks it first.

## What gets flagged

`malloc`, `realloc`, `alloca`, `xmalloc`, `g_malloc`, `kmalloc`, `vmalloc`, `HeapAlloc`, `LocalAlloc`, `GlobalAlloc` and C++ `new T[...]` whose size is a multiplication involving:

- a value parsed or decoded on the same line (`atoi`, `strtol` and friends, `ntohl`, `ntohs`, `beNNtoh`, `getenv`), or
- a variable assigned from one of those, or filled through `scanf`/`fscanf`/`sscanf`, `fread`, `read`, `recv`, `recvfrom`, `ReadFile` or `std::cin >>` or an extraction statement from any stream (`in >> w >> h;`), within the 20 lines above.

```c
uint32_t count = ntohl(*(const uint32_t *)buf);
out = malloc(count * sizeof(struct record));          // FLAGGED

int *table = (int *)malloc(atoi(argv[1]) * sizeof(int));  // FLAGGED

fscanf(fp, "%u", &n);
items = realloc(items, n * width);                    // FLAGGED

uint8_t *pixels = new uint8_t[w * h * 4];             // FLAGGED (w, h read from a stream)

read(fd, &nent, sizeof nent);
size_t bytes = nent * sizeof(struct entry);
e = malloc(bytes);                                    // FLAGGED: product computed above

int slots = atoi(arg);
if (slots <= 0) return NULL;                          // a lower bound only: not a check
p = malloc(slots * sizeof(long));                     // FLAGGED
```

## What is not flagged

- `calloc(count, size)` and `reallocarray`, which check the product.
- A count compared against a bound, or guarded with `SIZE_MAX`, `INT_MAX`, `__builtin_mul_overflow` or `ckd_mul`, between the read and the allocation.
- Products of constants or of internal counts (`cap * 2`, `MAX_ITEMS * sizeof(int)`, `strlen(s) * sizeof(char)`).
- Comments and string literals.

## Remediation

```c
uint32_t count = ntohl(*(const uint32_t *)buf);
if (count > SIZE_MAX / sizeof(struct record)) {
    return NULL;
}
struct record *out = calloc(count, sizeof(struct record));
```
