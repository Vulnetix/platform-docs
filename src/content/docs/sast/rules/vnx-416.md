## Overview

VNX-416 maps to [CWE-416: Use After Free](https://cwe.mitre.org/data/definitions/416.html). It covers two shapes that [VNX-C-004](/sast/rules/vnx-c-004/) (a pointer used after `free()`/`delete`) does not:

1. **The old pointer after `realloc`.** `q = realloc(p, n)` (also `reallocarray`, `g_realloc`, `g_try_realloc`, `OPENSSL_realloc`) into a different variable, followed within 15 lines by a dereference of `p` (`p->x`, `p[i]`, `*p`), a call that takes `p` or `p + off`, or `return p`, before `p` is reassigned. When `realloc` moves the block it frees the old one, so `p` dangles. Uses inside the branch that tests `q` for `NULL` are the failure path, where `p` is still valid, and are not reported.
2. **A pointer into a temporary (C++).** `const char *s = ...` or `return ...` of `c_str()`/`data()` on `std::string(...)`, `std::to_string(...)`, `std::format`/`fmt::format(...)`, a stringstream `.str()`, `.substr(...)` or a parenthesised concatenation; Qt `toUtf8()`/`toLatin1()`/`toLocal8Bit()` followed by `.constData()`/`.data()`; and a `std::string_view` initialised from such a temporary. The temporary is destroyed at the end of the statement.

## What Gets Flagged

```c
char *tmp = realloc(buf, len + n + 1);
if (!tmp) {
    free(buf);           // not flagged: realloc failed, buf is still valid
    return NULL;
}
memcpy(buf + len, s, n + 1);   // FLAGGED: buf may have been freed
```

```cpp
const char *label = std::to_string(port).c_str();   // FLAGGED
std::string_view key = std::to_string(id);          // FLAGGED
const char *key = name.toLatin1().constData();      // FLAGGED
```

## What Is Not Flagged

- `buf = tmp;` before the next use, and `p = realloc(p, n)` (a leak on failure, not a use after free).
- Pointer arithmetic such as `cur - base` used only to compute an offset.
- A temporary used within the same full expression: `printf("%s", std::to_string(n).c_str())`.
- `c_str()`/`data()` of a named string, comments and string literals.

## Remediation

Assign the result of `realloc` back after checking it, and keep strings alive in a named variable for as long as a pointer into them is used:

```c
char *tmp = realloc(buf, size);
if (tmp == NULL) { free(buf); return -1; }
buf = tmp;
```

```cpp
std::string label = std::to_string(port);
use(label.c_str());
```
