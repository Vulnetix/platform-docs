## Overview

VNX-681 maps to [CWE-681: Incorrect Conversion between Numeric Types](https://cwe.mitre.org/data/definitions/681.html). A length stored in a `uint16_t`, or a file size cast to `int`, silently wraps once the value is large enough. The truncated number then sizes a copy, an allocation or a seek, and the code works on test data and fails on the large input an attacker supplies.

## What gets flagged

```c
uint16_t name_len = strlen(name);        // FLAGGED: 8/16-bit from a length
out[2] = (uint8_t)strlen(name);          // FLAGGED: narrowing cast
int size = ftell(fp);                    // FLAGGED: file offset into int
pos = (int)ftello(fp);                   // FLAGGED

char c;
while ((c = fgetc(fp)) != EOF) { ... }   // FLAGGED: EOF test after narrowing to char
```

```java
byte[] buf = new byte[(int) uploadFile.length()];   // FLAGGED
int size = (int) Files.size(p);                     // FLAGGED
int len = (int) conn.getContentLengthLong();        // FLAGGED
short id = (short) System.currentTimeMillis();      // FLAGGED
```

C and C++: variables declared as `char`, `short`, `uint8_t`, `uint16_t`, `BYTE`, `WORD`, `USHORT` and similar, initialised from or cast from `strlen`, `wcslen`, `strnlen`, `ftell`, `ftello`, `lseek`, `read`, `recv`, `recvfrom`, `fread` or C++ `.size()`/`.length()`; and `int`/`unsigned int` from `ftell`/`ftello`/`lseek`. Java: casts to `int`, `short`, `byte` or `char` of `Files.size()`, `getContentLengthLong()`, `getSize()`, `getCompressedSize()`, `length()` on a file, `size()`/`position()` on a channel, `System.currentTimeMillis()` and `System.nanoTime()`.

## What is not flagged

- `int len = strlen(s)` and the `(int)strlen(s)` idiom for a printf precision.
- Conversions to `size_t`, `long`, `off_t`, `uint32_t` and wider.
- `Math.toIntExact(...)`, and casts of `int`-valued `size()`/`length()` calls on collections and strings.
- Comments and string literals.

## Remediation

Keep sizes in `size_t`/`off_t` (C) or `long` (Java). Where a narrower type is required by a format or protocol, check the range first and fail on overflow: `if (n > UINT16_MAX) return -1;` or `Math.toIntExact(file.length())`.
