## Overview

VNX-201 maps to [CWE-201: Insertion of Sensitive Information Into Sent Data](https://cwe.mitre.org/data/definitions/201.html). An API that serialises a database record straight into a response sends every column, including the password hash, the reset token and the API key. Anyone who can call the endpoint, or read a proxy log of it, gets them.

## What gets flagged

```javascript
res.json({ id: user.id, email: user.email, password: user.password });  // flagged

const user = await User.findByPk(req.params.id);
res.json(user);                                                          // flagged
```

```python
return jsonify({"id": user.id, "password_hash": user.password_hash})    # flagged
return jsonify(u.__dict__)                                               # flagged

class UserSerializer(serializers.ModelSerializer):
    class Meta:
        model = User
        fields = "__all__"                                                # flagged
```

```go
c.JSON(http.StatusOK, gin.H{"name": u.Name, "password": u.Password})    // flagged
```

```java
return ResponseEntity.ok(Map.of("login", user.getLogin(), "password", user.getPassword())); // flagged
```

Not flagged: masked or constant values (`"********"`), derived values (`password.length`, `password != ""`), field names that only start with a sensitive word (`passwordChangedAt`), lookups that project fields away (`.select('-password')`, `attributes: { exclude: [...] }`), records whose password is deleted before sending, projects that hide fields from serialisation (Mongoose `select: false` or `toJSON`, Jackson `@JsonIgnore`, Go `json:"-"`), serializers with `exclude` or a `write_only` password, and comments.

## Remediation

Return a response DTO with exactly the fields the client needs, or hide sensitive fields at the model:

```javascript
const UserSchema = new mongoose.Schema({ email: String, password: { type: String, select: false } });
res.json({ id: user.id, email: user.email });
```

```go
type User struct {
	Name     string `json:"name"`
	Password string `json:"-"`
}
```
