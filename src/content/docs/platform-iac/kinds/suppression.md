A suppression rule: findings that match its scope are suppressed, now and in every later scan, until it expires. Every apply writes the suppression audit. Rules created from a VexSource are owned by that source and cannot be declared here.

## Advanced

Every field the kind supports, with a `when` expression where it takes one. From `examples/Suppression/advanced.yaml`.

**YAML**

```yaml
apiVersion: vulnetix.com/v1
kind: Suppression
metadata:
  name: lodash-template-not-reachable
  labels:
    team: payments
  annotations:
    ticket: https://jira.example.com/browse/SEC-1234
spec:
  type: false_positive
  reason: lodash.template is never called with user input; the build only renders static templates.
  justification: vulnerable_code_not_in_execute_path
  scope:
    category: sca
    rule: CVE-2021-23337
    target: pkg:npm/lodash
    purl: pkg:npm/lodash@4.17.20
    path: web/package-lock.json
    line: 1204
    lineRange: 1204-1210
    repository: acme/storefront
    branch: main
  expires: 2027-06-30T00:00:00Z
  when: severity != 'critical' && !kev && repo == 'acme/storefront'
```

## CEL variables

`spec.when` is a CEL expression in the `finding` context, returning `bool`. It is evaluated by the suppression engine, over the findings a rule's anchors have already matched. **Fails open.** A finding the expression errors on is not suppressed. See [where each expression is evaluated](/platform-iac/reference/cel/#where-each-expression-is-evaluated). The functions, limits and error codes are on [CEL rule expressions](/platform-iac/reference/cel/).

## Applying this kind

- **Command.** `vulnetix config apply -f <file>`; the CLI line above says from which release. Plan first with [`vulnetix config plan`](/platform-iac/cli/plan/): it shows each object as create, update, delete or no change, with a `planHash` that apply then holds to. Apply writes in one transaction.
- **Manager.** Each object records the manager that applied it (`terraform`, `console` or `gitops:<repo>`). `--prune` deletes only objects its own manager owns. See [The manager](/platform-iac/cli/plan/#the-manager) and the [config engine](/platform-iac/reference/engine/).
- **Status.** Applied, Unchanged or Deleted, with no other status fields. The phases the engine reports are explained under [status phases](/platform-iac/reference/engine/#status-phases).

## How apply treats it

- The justification (the OpenVEX vocabulary), the expiry and `when` (stored as `expr`) are stored on the suppression.
- A rule owned by a VEX document or by a [`VexSource`](/platform-iac/kinds/vex-source/) cannot be changed or deleted through the engine.
- `when` is evaluated by the suppression engine, after the rule's anchors have matched; see [where each `when` runs](/platform-iac/reference/cel/#where-each-expression-is-evaluated).

## Terraform and OpenTofu

The resource is `vulnetix_suppression` in the `vulnetix/resolve` provider. Its arguments are the `spec` in snake case, beside `name`, `labels` and `annotations` from `metadata`.
