A Software Factory budget: a limit on the tokens or calls the factory spends, for the whole factory, one GitHub organisation, one repository, one workflow or one step, with alerts and an action at the limit. metadata.name is the budget's name in the console. One budget per scope and provider. The Factory budget (the whole factory, per month, every provider) is set with the budget settings of FactorySettings, not here. Removing the document deletes the budget; its ledger is kept.

## Applying this kind

- **Command.** `vulnetix config apply -f <file>`; the CLI line above says from which release. Plan first with [`vulnetix config plan`](/platform-iac/cli/plan/): it shows each object as create, update, delete or no change, with a `planHash` that apply then holds to. Apply writes in one transaction.
- **Manager.** Each object records the manager that applied it (`terraform`, `console` or `gitops:<repo>`). `--prune` deletes only objects its own manager owns. See [The manager](/platform-iac/cli/plan/#the-manager) and the [config engine](/platform-iac/reference/engine/).
- **Order.** Applied after [`FactoryWorkflow`](/platform-iac/kinds/factory-workflow/), so a document that refers to one by `metadata.name` can be in the same apply. Deleted before them.
- **Status.** Applied, Unchanged or Deleted, with no other status fields. The phases the engine reports are explained under [status phases](/platform-iac/reference/engine/#status-phases).

## How apply treats it

Through the budgets API's validator and writers, so a budget declared as code gets the same row, event and audit entry. The tenant's Factory budget belongs to [`FactorySettings`](/platform-iac/kinds/factory-settings/) (`budget.*`) and a repository's token cap to [`RepositorySettings`](/platform-iac/kinds/repository-settings/) (`monthlyTokenCap`). Neither is listed here, and a document for a scope and provider that one already covers is refused. Delete soft-deletes the row.
