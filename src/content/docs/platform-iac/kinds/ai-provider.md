A custom AI Firewall provider owned by the tenant: a model server the gateway forwards to, beside the built-in catalogue. Only this tenant sees or uses it. metadata.name is the provider slug, which becomes the gateway path prefix (/<slug>/<org>/v1/...) and is what AiFirewallPolicy providers and models refer to. A tenant has at most 10 custom providers, and a slug that a built-in provider uses is refused at apply.

## Applying this kind

- **Command.** `vulnetix config apply -f <file>`; the CLI line above says from which release. Plan first with [`vulnetix config plan`](/platform-iac/cli/plan/): it shows each object as create, update, delete or no change, with a `planHash` that apply then holds to. Apply writes in one transaction.
- **Manager.** Each object records the manager that applied it (`terraform`, `console` or `gitops:<repo>`). `--prune` deletes only objects its own manager owns. See [The manager](/platform-iac/cli/plan/#the-manager) and the [config engine](/platform-iac/reference/engine/).
- **Status.** Applied, Unchanged or Deleted, with no other status fields. The phases the engine reports are explained under [status phases](/platform-iac/reference/engine/#status-phases).

## How apply treats it

- Apply runs the console's own checks: the provider validator, the reserved built-in slugs, the public-host check on `baseUrl` and the cap of ten custom providers per tenant.
- The console has no update. Apply rewrites the same columns in place and keeps the provider's uuid, which the stored key's encryption context is bound to.
- `apiKey` is a secret. The client resolves it (`env` or `file`) on its own machine and sends it once. It is encrypted with the BYOK KMS key, never read back into a spec, exported or hashed. An export writes an `apiKey.env` placeholder, and a plan shows the key as changed only when the value you supply differs from the stored one.
- Deleting the object revokes the vault entries filed against the slug first, as deleting the provider in the console does.
- An [`AiFirewallPolicy`](/platform-iac/kinds/ai-firewall-policy/) that names the provider is applied after it.

## Terraform and OpenTofu

The resource is `vulnetix_ai_provider` in the `vulnetix/resolve` provider. Its arguments are the `spec` in snake case, beside `name`, `labels` and `annotations` from `metadata`. The Minimal and Advanced HCL are above. The provider's own reference is [vulnetix_ai_provider](https://registry.terraform.io/providers/vulnetix/resolve/latest/docs/resources/ai_provider).

Import an object that already exists by its name:

```shell
# Import an existing AiProvider by its name (metadata.name).
terraform import vulnetix_ai_provider.acme_vllm acme-vllm
```

A secret is two arguments, never stored in the plan or the state: `api_key_wo` (write-only) and `api_key_wo_version`. Change the version number to send a new value. See [Secrets](/platform-iac/terraform/#secrets).
