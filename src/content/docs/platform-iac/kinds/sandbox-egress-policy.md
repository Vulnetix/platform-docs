The outbound network policy of one Pix sandbox: its egress mode and the hostnames allowed or denied, the same two things the console's egress page sets. Egress is decided by hostname only, as the sandbox enforces it: a rule is a DNS name or a *. wildcard over one, never an address or a port. The hosts the sandbox needs for itself cannot be declared. A host decided in the console and left out of the document goes back to undecided on apply. Only an owner or admin can change it. Deleting the document resets the mode to inherit and every decision to undecided; the record of the hosts the sandbox reached stays.

## How apply treats it

- The mode plus hostname allow and deny lists. A host is a DNS name or a `*.` wildcard, never an address.
- A host decided in the console and left out of the document goes back to undecided. A system host cannot be declared.
- Owner or admin only. Delete resets the mode and every decision.
